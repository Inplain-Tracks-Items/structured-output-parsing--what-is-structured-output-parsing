# What is Structured Output Parsing

An introduction to Structured Output Parsing and its role in production AI and Forward Deployed Engineering systems.

Part of the **Structured Output Parsing** track on Inkplain Knowledge.

## How this repository works

Every step of the lesson has its own branch, and each one contains all steps up to it:

```bash
git clone https://github.com/Inplain-Tracks-Items/structured-output-parsing--what-is-structured-output-parsing.git
cd structured-output-parsing--what-is-structured-output-parsing
git branch -r            # list the step branches
git checkout step-01-…   # code after step 1
```

`main` holds the final, complete version.
